init-completion.el 
;; ==========================================
;; 1. EGLOT (LSP Completion Backend)
;; ==========================================
(use-package eglot
  :ensure nil
  :custom
  (eglot-completion-at-point t))
;; ==========================================
;; 2. CORFU (In-Buffer Completion UI)
;; ==========================================
(use-package corfu
  :init (global-corfu-mode)
  :custom
  (global-corfu-minibuffer nil)
  (corfu-auto t)
  (corfu-auto-delay 0.2)
  (corfu-auto-prefix 2)
  (corfu-preselect 'prompt)
  :bind (:map corfu-map
         ("TAB" . corfu-next)
         ("RET" . corfu-insert)
         ("<escape>" . corfu-quit)))
Why This Approach?

PerformanceExponentially lighter; zero main-thread blocking during typing.
FilteringIntegrates with orderless for out-of-order fuzzy matching.
Emacs 31Leverages native TTY child-frames and PGTK Wayland fixes.

✕ company + lsp-mode · Rejected

ArchitectureCustom overlay engine and heavy workspace management.
PerformanceProne to micro-stutters and "stutter-and-vanish" popup bugs.
FilteringRequires company-flx; struggles with space-separated queries.
ProtocolBreaks the eglot-only stack mandate.
Emacs 31 Specific Enhancements
TTY Child-Frame Support

Introduces tty-tip-mode and native TTY child-frames. Allows corfu to render perfectly in terminals like Ghostty or Kitty.

PGTK Wayland Fixes

Child-frame positioning is now pixel-accurate. Eliminates the "drifting popup" bug, ensuring Corfu anchors to the cursor baseline.

Eager Display API

completion-eager-display ensures the native *Completions* fallback appears immediately if Corfu is bypassed.

init-hover.el 
;; ==========================================
;; 2. ELDOC CORE (Emacs Native Rendering)
;; ==========================================
(use-package eldoc
  :ensure nil
  :custom
  ;; Surface `help-at-point-kbd-string` through the eldoc pipeline.
  (eldoc-help-at-pt t)
  ;; Prefer the ephemeral `*eldoc*` buffer over the echo area
  ;; when documentation exceeds a single line.
  (eldoc-echo-area-prefer-doc-buffer t)
  (eldoc-echo-area-use-multiline-p t)
  (eldoc-idle-delay 0.5)
  :config
  (global-eldoc-mode 1))

;; ==========================================
;; 3. CORFU-POPUPINFO (Candidate-Level Hover)
;; ==========================================
(use-package corfu-popupinfo
  :ensure nil
  :after corfu
  :bind (:map corfu-map
         ("M-h" . corfu-popupinfo-toggle))
  :config
  (corfu-popupinfo-mode 1)
  ;; Documentation is ONLY shown on manual trigger (M-h).
  (setq corfu-popupinfo-delay nil))

;; ==========================================
;; 4. GENERAL.EL KEYBINDINGS
;; ==========================================
(general-define-key
  :states 'normal
  "K" #'eldoc)

;; ==========================================
;; 1. ELDOC-BOX (GUI Childframe Hover)
;; ==========================================
(use-package eldoc-box
  :ensure t
  :after eglot
  :custom
  (eldoc-box-clear-after-use t)
  (eldoc-box-only-multi-line t)
  (eldoc-box-offset '(10 10 10))
  :custom-face
  (eldoc-box-border ((t (:background "#292e42"))))
  (eldoc-box-default-face ((t (:background "#1a1b26" :foreground "#c0caf5"))))

  (eldoc-box-hover-at-point-mode 1))

init-signature.el 
;; ==========================================
;; 1. ELDOC CORE (Signature & Hover Routing)
;; ==========================================
(use-package eldoc
  :ensure nil
  :custom
  ;; When a signature exceeds the echo area, automatically route it
  ;; to the ephemeral `*eldoc*` buffer instead of expanding the echo area.
  (eldoc-echo-area-prefer-doc-buffer t)
  (eldoc-echo-area-use-multiline-p t)
  (eldoc-idle-delay 0.5)
  (eldoc-help-at-pt t)
  :config
  ;; Enable eldoc globally. eglot-managed buffers automatically inject
  ;; `eglot-signature-eldoc-function` into `eldoc-documentation-functions`.
  (global-eldoc-mode 1))

Emacs 31 Specific Enhancements
eldoc-echo-area-prefer-doc-buffer (NEW)

In older Emacs versions, long C++ template signatures would truncate or force the echo area to expand to 5+ lines, causing severe UI jitter. Emacs 31 routes oversized signatures to a dedicated, scrollable *eldoc* buffer.

markdown-ts-mode Integration

When signatures are routed to the *eldoc* buffer, Emacs 31's native tree-sitter markdown mode fontifies any code blocks or type annotations embedded in the signature documentation at C-speed.

elisp-eldoc-funcall-with-docstring

For Emacs Lisp buffers, Emacs 31's native eldoc engine now merges the function signature with its docstring in a single, highly optimized payload, reducing the need for separate hover queries.

TTY-Safe Degradation

Unlike child-frame-based signature widgets, eldoc degrades gracefully to the echo area or standard window splits over SSH/TTY, ensuring signature help is always accessible in terminal environments.
