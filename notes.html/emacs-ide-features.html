Setup & core philosophy

This stack assumes Emacs 31 (PGTK, native-comp AOT) and treats eglot as the only LSP client. Everything network-bound is bypassed in favour of native treesit, xref, flymake, and eldoc. Notably, Emacs 31's richer eldoc output and flymake's new fancy end-of-line diagnostics render third-party packages like eldoc-box and flyover unnecessary.

;; core stack — one block to rule them all (use-package eglot :ensure nil ;; built into Emacs 31 :hook ((python-ts-mode . eglot-ensure) (typescript-ts-mode . eglot-ensure) (rust-ts-mode . eglot-ensure) (go-ts-mode . eglot-ensure)) :config (setq eglot-events-buffer-size 0 ;; drop the JSON-RPC log eglot-sync-connect nil ;; never block on launch eglot-connect-timeout 30 eglot-autoshutdown t) (add-to-list 'eglot-server-programs '((python-ts-mode) . ("pyright-langserver" "--stdio"))))
;; supporting cast — each package is one job, done well (use-package corfu :config (global-corfu-mode) (corfu-popupinfo-mode)) (use-package corfu-candidate-overlay :after corfu :config (corfu-candidate-overlay-mode +1)) (use-package vertico :config (vertico-mode)) (use-package consult :config (consult-eglot-mode +1)) (use-package apheleia :config (apheleia-global-mode +1)) (use-package treesit-fold :config (global-treesit-fold-mode)) (use-package expreg) (use-package dape :config (setq dape-inline-variables t))
;; Emacs 31 eldoc — rich markdown rendering, no eldoc-box needed (setq eldoc-help-at-pt t ;; show help-at-pt via eldoc eldoc-echo-area-prefer-ephemeral-buffer t) ;; Emacs 31 flymake — native fancy inline diagnostics, no flyover needed (setq flymake-show-diagnostics-at-end-of-line 'fancy flymake-indicator-type 'auto) ;; fringes → margins fallback

Completion & intelligence

The IntelliSense surface: popups, ghost text, hover docs, signature help and type-aware highlighting — all without the heavy lsp-mode ecosystem.

M-x filter/ 6 features

IntelliSense / code completion (VS Code autocomplete)

working

Context-aware popup with ghost text, auto-import on accept, and live resolve. eglot drives completion-at-point via eglot-completion-at-point, corfu renders the minimal popup, and corfu-candidate-overlay draws the inline preview. On TTY frames, Emacs 31's new TTY child-frame support (see tty-tip-mode) lets corfu render correctly even in the terminal.

eglot corfu corfu-candidate-overlay completion-at-point corfu-next corfu-insert
triggers TAB C-n / C-p RET lsp completionItem/resolve

Hover info (tooltip on hover)

emacs 31 · no eldoc-box

Type info, docstrings and signatures rendered in rich markdown via markdown-ts-mode. eglot integrates natively with eldoc; the new eldoc-help-at-pt user option surfaces help-at-pt-kbd-string through eldoc. corfu-popupinfo lets you pull docs for the active candidate on demand (M-h). Emacs 31's richer eldoc output renders markdown correctly in ephemeral buffers, making eldoc-box unnecessary.

eglot eldoc corfu-popupinfo eldoc corfu-popupinfo-toggle
triggers K M-h hover new var eldoc-help-at-pt

Signature help (parameter hints)

native eldoc

Active-parameter highlighting while typing inside a function call. eglot implements textDocument/signatureHelp and routes it through eldoc. Emacs 31's eldoc displays signatures directly in the echo area with the new elisp-eldoc-funcall-with-docstring engine and elisp-eldoc-docstring-length-limit (default 1000 chars), rendering rich parameter info without any third-party frame package.

eglot eldoc eldoc elisp-eldoc-funcall-with-docstring
triggers C-h . K

Semantic tokens (type-aware coloring)

native · treesit

Type-aware syntax colouring beyond static grammars. Emacs 31's treesit runs at C speed with treesit-font-lock-level set to 4 — zero latency, zero network. Emacs Lisp now ships its own semantic highlighter via the new elisp-fontify-semantically user option. eglot supplements with LSP semantic tokens only when the server advertises semanticTokensProvider.

treesit eglot treesit-font-lock-level elisp-fontify-semantically
automatic treesit-font-lock-level 4

Inlay hints (inline type annotations)

working

Inline grey annotations for inferred types, parameter names and return types. eglot natively implements textDocument/inlayHint and inlayHint/resolve. In Emacs 31 the overlay renderer is faster and respects variable-pitch fonts when eglot-inlay-hints-mode is toggled.

eglot eglot-inlay-hints-mode
toggle SPC t h

Inline values (debugger inline variables)

via DAP

Variable values at end-of-line while paused in the debugger. Not LSP — it's the Debug Adapter Protocol, handled by dape. Set (setq dape-inline-variables t) to enable overlays. Bypasses the heavy dap-mode stack.

dape dape-inline-variables

Navigation & code jumping

Jump to definition, declaration, type, implementation and references — all routed through Emacs' native xref framework, with shared history. Emacs 31 adds mouse-mode and editable xref buffers.

M-x filter/ 7 features

Go to Definition (F12 / Ctrl+Click)

working

Jump to where a symbol is defined, with peek-like previews via xref-show-definitions-function. eglot implements textDocument/definition through xref, with native history tracking via xref-go-back. Emacs 31's new xref-mouse-mode adds Ctrl+Click jump-to-definition — matching VS Code conventions.

eglot xref xref-find-definitions xref-go-back global-xref-mouse-mode
keys M-. M-, C-<mouse-1>

Go to Declaration (header jump)

working

Jump to a symbol's declaration — distinct from definition in C/C++ headers or TypeScript interfaces. eglot natively exposes textDocument/declaration.

eglot eglot-find-declaration
key C-c d

Go to Type Definition (Ctrl+F12)

working

Jump to the type definition of a variable or expression. Routes textDocument/typeDefinition through xref for classes, interfaces, and type aliases.

eglot xref eglot-find-typeDefinition
key C-c t

Go to Implementation (Ctrl+F12)

working

Jump to concrete implementations of an interface method or abstract class. eglot presents a navigable list via completing-read.

eglot xref eglot-find-implementation
key C-c i

Find All References (Shift+F12)

editable in emacs 31

Lists every usage of a symbol across the project in a navigable xref buffer. eglot implements textDocument/references; pair with consult-xref for vertico-style filtering. Emacs 31's new xref-change-to-xref-edit-mode (bound to e) makes the xref buffer editable, mirroring the Grep-Edit workflow — changes propagate back to originating files.

eglot xref xref-find-references xref-change-to-xref-edit-mode
key M-? e

Call Hierarchy (callers/callees tree)

working

Interactive tree of who calls a function and what it calls. eglot implements textDocument/prepareCallHierarchy, callHierarchy/incomingCalls and callHierarchy/outgoingCalls.

eglot eglot-show-call-hierarchy
key SPC c h

Type Hierarchy (supertypes/subtypes)

working

Tree view of a type's supertypes and subtypes. Implements the LSP 3.17 textDocument/prepareTypeHierarchy family.

eglot eglot-show-type-hierarchy
key SPC c t

Code actions & refactoring

Lightbulb menu, code lens, safe rename, and server-defined commands — the refactor surface.

M-x filter/ 5 features

Code Actions (lightbulb menu)

working

Quick fixes, extract method/variable, add missing import. eglot implements textDocument/codeAction and codeAction/resolve, presented as a searchable completing-read menu that integrates with vertico.

eglot eglot-code-actions eglot-code-action-organize-imports
keys SPC c a SPC c i

Code Lens (inline actionable annotations)

working

Inline clickable annotations above symbols (e.g., "1 reference | Run Test | Debug Test"). eglot handles textDocument/codeLens and codeLens/resolve; a lightweight custom extension renders them as overlays.

eglot eglot-codelens eglot-codelens-mode
toggle SPC c l mouse-1

Rename Symbol (F2)

working

Project-wide safe rename of a symbol and all its references. eglot implements textDocument/rename and textDocument/prepareRename with AST-aware text edits across the entire project. Text-based alternatives (wgrep, iedit) are inherently unsafe.

eglot eglot-rename
key F2 SPC c r

Execute Command (command palette entries)

working

Server-defined custom commands surfaced in the command palette, e.g. "Organize Imports". eglot exposes workspace/executeCommand.

eglot eglot-execute-command eglot-code-action-organize-imports
key SPC c x

Document Highlight (highlight occurrences)

working

Highlights all occurrences of the symbol under the cursor within the current file via overlays styled with eglot-highlight-symbol-face.

eglot eglot--managed-mode

Diagnostics & symbols

Errors, warnings, outline views and workspace-wide symbol search. Emacs 31's new fancy flymake rendering eliminates the need for flyover.

M-x filter/ 5 features

Diagnostics (push model) (Problems panel)

fancy · no flyover

Server pushes errors and warnings; rendered as squiggles and listed in the diagnostics buffer. eglot routes textDocument/publishDiagnostics to flymake. Emacs 31's new flymake-show-diagnostics-at-end-of-line 'fancy value lays out diagnostics below the affected line using Unicode graphics that point back to the locus — effectively replacing flyover with native, richer rendering. flymake-show-buffer-diagnostics now highlights the nearby diagnostic in the listing and is bound to fringe/margin clicks.

eglot flymake flymake-show-buffer-diagnostics consult-flymake
keys SPC c e SPC c n new var flymake-show-diagnostics-at-end-of-line 'fancy

Diagnostics (pull model) (LSP 3.17+)

working

Client requests diagnostics on demand, including workspace-wide refresh. eglot supports textDocument/diagnostic and workspace/diagnostic from LSP 3.17+.

eglot flymake flymake-start
key SPC c !

Document Symbols (Outline + breadcrumb)

working

Tree view of classes, functions, and variables in the current file; also powers the breadcrumb dropdown. consult-eglot-symbols renders a preview-enabled outline in the minibuffer; eglot-header-line-mode provides native clickable breadcrumbs. Emacs 31's new treesit-aggregated-simple-imenu-settings powers multi-language imenu trees for modes like mhtml-ts-mode and php-ts-mode.

eglot consult consult-eglot-symbols eglot-header-line-mode
keys SPC c s SPC t b

Workspace Symbol search (Ctrl+T)

working

Fuzzy search symbols across the whole project. consult-eglot-symbols uses completing-read with live preview for workspace/symbol.

eglot consult consult-eglot-symbols
key SPC s w C-t

Moniker (cross-repo symbol id)

working

Cross-repository symbol identity for large-scale indexed navigation. eglot supports textDocument/moniker (LSP 3.16+) and resolves identifiers like npm:lodash:4.17.21:map for external indexers (LSIF, Sourcegraph).

eglot eglot--managed-mode

Formatting & editing

Async whole-file formatting, AST-aware range formatting, native folding and smart selection.

M-x filter/ 5 features

Document Formatting (whole file)

async · apheleia

Asynchronously formats the entire current file using external CLI tools. apheleia runs the formatter in the background, computes a safe diff, and applies the changes while preserving cursor position, mark and undo history — bypassing the synchronous LSP formatting protocol entirely.

apheleia apheleia-format-buffer
key SPC c f

Range Formatting (selection only)

via ruff

Formats the active region using ruff format --range, providing context-aware AST formatting for selections without fragile text-splicing hacks. A custom DWIM function delegates regions to the CLI; whole-file ops fall back to apheleia.

ruff ar/format-dwim
key SPC c f with region

On-type Formatting (auto-indent on trigger)

native · no LSP

Auto-reformats as you type trigger characters like } or ;. Intentionally omitted from LSP to prevent main-thread blocking — Emacs' electric-indent-mode, electric-pair-mode (now supports multi-character pairs like /* */ in Emacs 31), and electric-layout-mode handle structural re-indentation and auto-pairing in microseconds with zero network latency.

electric electric-pair electric-indent-mode electric-pair-mode electric-layout-mode

Folding Ranges (gutter arrows)

native · treesit

Collapse/expand code blocks, functions, imports and regions. treesit-fold provides AST-aware folding with native fringe indicators. Emacs 31's hideshow gains hs-cycle, hs-toggle-all, a new hs-indentation-mode for indentation-based blocks, and configurable hs-indicator-type (fringe / margin / eol) — tree-sitter modes now properly support hideshow via the new list thing.

treesit-fold hideshow hs-cycle hs-toggle-all hs-indentation-mode
keys za zo zc

Selection Range (Shift+Alt+arrows)

native · treesit

Grow/shrink selection by syntactic scope. expreg provides iterative expansion loops; Emacs 31's new treesit-cycle-sexp-thing lets you toggle between list and sexp navigation on the fly.

expreg treesit-thing expreg-expand expreg-contract treesit-cycle-sexp-thing
keys M-= C-M--

Visual enhancements

Clickable links, color swatches, paired tag editing and show-paren powered by treesit.

M-x filter/ 4 features

Document Links (Ctrl+click URLs)

working

Clickable URLs, file paths and import references inside source and comments. eglot handles textDocument/documentLink for imports; goto-address-mode and ffap provide zero-latency local link resolution. Emacs 31's ffap-prefer-remote-file option enables remote-first FFAP in Tramp buffers.

eglot goto-address ffap goto-address-mode ffap
keys mouse-1 C-c C-o RET

Document Color (color swatches)

working

Inline colour swatches next to CSS-like colour values, with a picker. eglot natively supports textDocument/documentColor and textDocument/colorPresentation.

eglot eglot--managed-mode

Linked Editing Range (rename HTML pair)

native · auto-rename-tag

Editing one HTML/JSX tag name automatically updates its matching pair. auto-rename-tag provides this locally using Emacs' native parsing, ensuring zero network latency.

auto-rename-tag auto-rename-tag-mode
trigger typing

Match highlighting (paren / bracket pair)

treesit-aware in 31

Highlights the matching delimiter at point. Emacs 31's treesit-show-paren-data function lets show-paren-mode use the tree-sitter parse tree, giving structural (not just syntactic) matching for languages like JSX, Rust and Go. The new show-paren-not-in-comments-or-strings option suppresses noise inside comments.

treesit show-paren-mode treesit-show-paren-data
trigger cursor on paren

Workspace & files

Server notifications for file operations — keeping imports in sync when files move.

M-x filter/ 1 feature

Workspace file-operation hooks (auto-fix imports on rename)

working

Automatically fixes imports and references when files are renamed, moved or deleted. A custom wrapper ar/eglot-rename-file-and-update-imports signals workspace/willRenameFiles, performs the rename, then fires workspace/didRenameFiles. Emacs 31's new vc-rename-file (C-x v R) integrates cleanly with this flow.

eglot ar/eglot-rename-file-and-update-imports vc-rename-file
key C-x v R

Emacs 31 deltas

Notable changes in Emacs 31 (PGTK, native-comp AOT) that affect the IDE surface. All items below have been verified against the NEWS.31 changelog.

IDE-critical changes 12 items
replaces eldoc-box
Rich eldoc output. New eldoc-help-at-pt user option; elisp-eldoc-funcall-with-docstring and elisp-eldoc-docstring-length-limit (1000 chars) render full docstrings in the echo area or ephemeral buffers. eldoc-box is no longer required.
replaces flyover
Flymake 'fancy end-of-line diagnostics. flymake-show-diagnostics-at-end-of-line now accepts the value 'fancy, laying out diagnostics below the affected line using Unicode graphics that point back to the locus. flyover is no longer required.
new
Flymake API extensions. flymake-make-diagnostic accepts origin and code attributes; flymake-diagnostic-format-alist gives per-context control; flymake-indicator-type 'auto (default) prefers fringes and falls back to margins.
new
flymake-show-buffer-diagnostics enhanced. Now highlights the nearby diagnostic in the listing and responds to fringe/margin mouse clicks. Column widths dynamically adjust to content.
new
xref-mouse-mode. Binds xref-find-definitions-at-mouse to C-<down-mouse-1>; global-xref-mouse-mode enables Ctrl+Click definition jumps globally.
new
xref-change-to-xref-edit-mode. Bound to e in xref buffers — turns the references buffer into an editable surface like Grep-Edit, with edits propagating back to originating files.
built-in
Native treesit now default in *-ts-modes. Python, TypeScript, Rust, Go and 18 other languages ship with native tree-sitter major modes. treesit-auto-install-grammar auto-installs missing grammars.
built-in
treesit + show-paren + hideshow integration. treesit-show-paren-data powers structural paren matching; hideshow now works correctly on tree-sitter modes via the new list thing. New hs-cycle, hs-toggle-all, hs-indentation-mode.
built-in
Semantic highlighting for Emacs Lisp. New elisp-fontify-semantically user option uses code analysis for more accurate symbol highlighting in emacs-lisp-mode.
built-in
TTY child-frame support. Corfu, Posframe and tooltip child-frames now render correctly on TTY frames via tty-tip-mode. Feature detection: (featurep 'tty-child-frames).
built-in
PGTK child-frame fixes. Child-frame positioning on Wayland is now pixel-accurate, fixing hover docs and corfu popups that drifted under GNOME + mutter.
deprecated
lsp-mode no longer necessary. With Emacs 31's eglot, every feature formerly exclusive to lsp-mode (peek, sideline, codelens, imenu sidebar) is either built-in or replaced by a lighter native alternative. Not recommended for new configurations.
Navigation & editing helpers 8 items
new
treesit-cycle-sexp-thing. Toggle between list and sexp navigation for treesit-forward-sexp / treesit-forward-list.
new
Multi-language treesit support. treesit-aggregated-simple-imenu-settings and treesit-aggregated-outline-predicate power multi-language imenu/outline for modes like mhtml-ts-mode and php-ts-mode.
new
treesit-language-remap-alist. Remap one tree-sitter language to another to reuse font-lock and indent rules (e.g., TypeScript → TSX).
new
New comment treesit thing. forward-comment-function is set to treesit-forward-comment when a mode defines it.
new
electric-pair-mode multi-character delimiters. electric-pair-pairs accepts strings for pairs like ("/*" . "*/") with optional auto-spacing.
new
electric-layout-mode. Now supported in python-ts-mode and other major modes for automatic line layout on trigger characters.
new
show-paren-not-in-comments-or-strings. Suppress paren highlighting inside comments/strings (values: nil, all, on-mismatch).
new
Completions eager display. completion-eager-display and completion-eager-update control whether *Completions* appears immediately and updates as you type — helpful for LSP completion tables.
Project & workspace plumbing 6 items
new
vc-rename-file bound to C-x v R. Hooks cleanly into workspace/willRenameFiles for eglot-driven import updates.
new
vc-auto-revert-mode. Like global-auto-revert-mode but limited to VCS-tracked files — reliable buffer refresh after VCS operations.
new
Multi-worktree commands. C-x v w family manages Git worktrees and Mercurial share extensions.
new
project-mode-line 'non-remote. Show project name on the mode line only for local files, cutting noise over Tramp.
new
user-lisp-directory auto-scrape. Files in user-lisp/ are byte-compiled, autoload-scraped and load-path'd automatically — replaces package-vc-install-from-checkout.
deprecated
package-vc-install-from-checkout obsolete. Use the User Lisp directory instead. :vc + :load-path combinations in use-package are obsolete.
