01 / installation & core setup

Getting started

The standard use-package block. Use lsp to connect immediately, or lsp-deferred to wait until the buffer is actually shown — worth it if you open many files at once.

(use-package lsp-mode
  :init
  (setq lsp-keymap-prefix "C-c l")   ;; or "s-l" (default), or "C-l"
  :hook ((XXX-mode . lsp)            ;; replace XXX-mode with your major mode
         (lsp-mode . lsp-enable-which-key-integration))
  :commands lsp)

Minimal vanilla template (from the official C/C++ IDE guide)

(require 'package)
(add-to-list 'package-archives ("melpa" . "https://melpa.org/packages/"))
(package-initialize)
(unless (package-installed-p 'lsp-mode) (package-refresh-contents) (package-install 'lsp-mode))
(setq lsp-keymap-prefix "C-c l")
(require 'lsp-mode)
(add-hook 'c-mode-hook #'lsp)
(add-hook 'c++-mode-hook #'lsp)

Doom Emacs and Spacemacs both ship their own lsp-mode module layers — prefer those flags over a raw use-package block if you're on a framework. lsp-mode auto-activates lsp-ui as long as lsp-auto-configure is non-nil.

03 / default keybindings

Keybindings

Everything lives under lsp-command-map, prefixed by lsp-keymap-prefix — s-l by default.

KeyAction

which-key integration

(with-eval-after-load 'lsp-mode
  (add-hook 'lsp-mode-hook #'lsp-enable-which-key-integration))

Pass t to lsp-enable-which-key-integration to enable it globally across major modes — useful for buffers like vue-mode that switch major modes.

06 / extension

lsp-ui

Bundles the higher-level UI: sideline info, VS Code–style peek, hover doc frames, and an imenu sidebar. Auto-activates with lsp-mode when lsp-auto-configure is non-nil.

(use-package lsp-ui
  :commands lsp-ui-mode)

Shows info for the symbol on the current line — flycheck diagnostics and available code actions rendered inline at end-of-line.

VariablePurpose

A VS Code–style "peek" UI for cross references, shown inline without leaving the buffer.

Command / variablePurpose
(define-key lsp-ui-mode-map [remap xref-find-definitions] #'lsp-ui-peek-find-definitions)
(define-key lsp-ui-mode-map [remap xref-find-references] #'lsp-ui-peek-find-references)

Shows documentation for the symbol at point in a child frame, or an embedded WebKit widget on xwidget builds.
