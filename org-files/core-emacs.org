* Core Emacs
This section forms the foundational bedrock of the Emacs configuration. It handles the critical bootstrap sequence, package management, deep performance tuning, session persistence, and cross-platform environment normalization. Every setting here is meticulously optimized for Emacs 30/31, ensuring that the editor remains responsive, mathematically safe across different operating systems, and capable of handling heavy, modern IDE workloads (like LSP and Tree-sitter) without stuttering.

** Lexical Binding
Lexical binding is a strict requirement for modern Emacs Lisp. Unlike dynamic binding, lexical binding scopes variables to their enclosing block, enabling the use of closures, preventing subtle variable-bleeding bugs, and allowing the byte-compiler to generate significantly faster, optimized machine code. The `no-byte-compile: t` directive in the header ensures that Emacs does not attempt to prematurely compile this tangled file before `compile-angel` has registered its exclusion rules.

#+begin_src emacs-lisp
;;; init.el --- Main Configuration File -*- no-byte-compile: t; lexical-binding: t; -*-
;;; Commentary:
;; This file is auto-generated by tangling `config.org`.
;; Lexical binding is enabled globally for this file via the header above.
#+end_src

** Package Management
This section initializes the built-in *package.el* system. It configures the standard archives (GNU, NonGNU, MELPA) and bootstraps the *no-littering* package. *no-littering* is essential for maintaining a clean *~/.config/emacs* directory by redirecting the hundreds of state, cache, and configuration files generated by various packages into organized *var/* and *etc/* subdirectories. Finally, it bootstraps *use-package*, the declarative macro that powers the lazy-loading architecture of the rest of the configuration.

#+begin_src emacs-lisp
;; Prefer newer versions of files when loading (e.g., .el over .elc if edited).
;; This prevents Emacs from silently loading stale byte-compiled artifacts
;; when you are actively debugging or modifying Elisp source files.
(setq load-prefer-newer t)

;; Redirect ELPA packages to a subdirectory to keep the root directory clean.
(setq package-user-dir (expand-file-name "var/elpa/" user-emacs-directory))

(require 'package)
;; Define the package archives. GNU and NonGNU provide stable, FSF-approved
;; packages, while MELPA provides the latest rolling releases from GitHub.
(setq package-archives '(("gnu" . "https://elpa.gnu.org/packages/")
                         ("nongnu" . "https://elpa.nongnu.org/nongnu/")
                         ("melpa" . "https://melpa.org/packages/")))
(package-initialize)

;; Refresh archive contents if they are missing (e.g., on a fresh install).
;; Note: This forces a synchronous network request. On subsequent startups,
;; `package-archive-contents` will be populated from the local cache, skipping
;; this step and preventing network latency from blocking Emacs startup.
(unless package-archive-contents
  (package-refresh-contents))

;; Bootstrap `no-littering` to manage Emacs file paths cleanly.
;; This must happen before any other packages are loaded so they respect
;; the XDG-like directory structure it enforces.
(unless (package-installed-p 'no-littering)
  (package-install 'no-littering))
(require 'no-littering)

;; Redirect the custom.el file (where Emacs saves UI customizations)
;; to the no-littering etc/ directory to prevent it from polluting init.el.
(setq custom-file (no-littering-expand-etc-file-name "custom.el"))
(when (file-exists-p custom-file)
  (load custom-file))

;; Theme backup files (e.g., #file# or .~1~) to prevent them from cluttering
;; the working directory, moving them to a centralized backup location.
(no-littering-theme-backups)

;; Local personal libraries (for custom .el files stored in ~/.config/emacs/lisp)
(add-to-list 'load-path (expand-file-name "lisp" user-emacs-directory))

;; Bootstrap `use-package` for declarative, lazy-loading configuration.
;; `eval-when-compile` ensures the macro is available during byte-compilation.
(eval-when-compile (require 'use-package))
(require 'bind-key)
(setq use-package-verbose nil             ; Suppress verbose loading logs
      use-package-expand-minimally t      ; Reduce compiled file size
      use-package-always-ensure t         ; Auto-install missing packages via package.el
      use-package-compute-statistics nil  ; Disable profiling overhead for faster startup
      use-package-enable-imenu-support t) ; Allow imenu to jump to use-package blocks
#+end_src

** Compile Angel
`compile-angel` automatically byte-compiles and native-compiles Emacs Lisp files in the background, ensuring that your configuration and installed packages always run at maximum C-level speed. Crucially, this section configures explicit exclusions for frequently written state files (`savehist`, `recentf`, `custom-file`). Compiling these files would cause severe I/O locks, async compilation warnings, and unnecessary CPU cycles, as they contain serialized data structures, not executable code.

#+begin_src emacs-lisp
;; Exclude anything you don't want silently compiled (adjust to taste)
;; (setq compile-angel-excluded-files-regexps '("/\\.dir-config\\.el$"))

(use-package compile-angel
  :demand t
  :config
  (setq compile-angel-verbose t)
  ;; Prevent compile-angel from compiling the core init files.
  ;; Tangling and compiling these simultaneously can cause race conditions.
  (push "/init.el" compile-angel-excluded-path-suffixes)
  (push "/early-init.el" compile-angel-excluded-path-suffixes)
  ;; Automatically compile elisp files on save
  (add-hook 'emacs-lisp-mode-hook #'compile-angel-on-save-local-mode))

(setq compile-angel-enable-byte-compile t)
(setq compile-angel-enable-native-compile t)
;; Don't leave half-finished .eln files in /tmp if you quit mid-compile.
;; This forces Emacs to wait for the native-comp worker to finish or abort cleanly.
(setq native-comp-async-query-on-exit t)
(setq confirm-kill-processes t)

;; Exclude state files that are frequently written to prevent I/O locks
;; and native-comp warnings on non-code data structures.
;; We use `with-eval-after-load` to ensure the variables are defined
;; before we attempt to read their file paths.
(with-eval-after-load "savehist"
  (push (concat "/" (file-name-nondirectory savehist-file))
        compile-angel-excluded-path-suffixes))
(with-eval-after-load "recentf"
  (push (concat "/" (file-name-nondirectory recentf-save-file))
        compile-angel-excluded-path-suffixes))
(with-eval-after-load "cus-edit"
  (when (stringp custom-file)
    (push (concat "/" (file-name-nondirectory custom-file))
          compile-angel-excluded-path-suffixes)))

;; Only now, with exclusions registered, turn on the interception itself.
;; This globally monitors `load` and `require` calls and compiles missing .elc/.eln files.
(compile-angel-on-load-mode)
#+end_src

** Custom Functions
A collection of utility functions used throughout the configuration. These include robust checks for childframe and icon support (essential for UI packages like `corfu` and `nerd-icons`), a comprehensive configuration reloader that calculates load times, and an auto-tangler that seamlessly compiles the literate `config.org` upon saving.

#+begin_src emacs-lisp
(defun childframe-workable-p ()
  "Whether childframe is workable.
Childframes are floating windows used by packages like `corfu` and `posframe`.
They require a graphical display or a terminal emulator that supports them."
  (and (not noninteractive)
       (or (display-graphic-p)
           (featurep 'tty-child-frames))
       (eq (frame-parameter (selected-frame) 'minibuffer) 't)))

(defun childframe-completion-workable-p ()
  "Whether childframe completion is workable."
  (childframe-workable-p))

(defun icons-displayable-p ()
  "Return non-nil if icons are displayable.
Checks if nerd-icons is loaded or can be loaded, ensuring we don't
attempt to render icon fonts in environments that lack them."
  (or (featurep 'nerd-icons)
      (require 'nerd-icons nil t)))

(defun too-long-file-p ()
  "Check whether the file is too long.
Used to disable expensive minor modes (like `flycheck` or `lsp-mode`)
in massive files (e.g., minified JSON or large log files) to prevent freezing."
  (or (> (buffer-size) 500000)
      (and (fboundp 'buffer-line-statistics)
           (> (car (buffer-line-statistics)) 10000))))

(defun reload-init-file ()
  "Tangle and reload the Emacs configuration from config.org.
This function is designed for use with package.el.
IMPORTANT: This does NOT fully restart Emacs. Some changes (especially
removed keybindings, hooks, or modes) will persist until you restart Emacs."
  (interactive)
  (let* ((config-org (expand-file-name "config.org" user-emacs-directory))
         (init-el (expand-file-name "init.el" user-emacs-directory))
         (start-time (current-time)))
    ;; Check if config.org exists
    (unless (file-exists-p config-org)
      (user-error "Configuration file %s not found!" config-org))
    ;; Confirm before reloading
    (when (yes-or-no-p "Reload configuration? (This won't reset removed keybindings/hooks) ")
      (message "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━")
      (message "Tangling configuration from config.org...")
      ;; Ensure Org is loaded before tangling
      (require 'org)
      ;; Tangle the org file
      (condition-case err
          (org-babel-tangle-file config-org init-el "emacs-lisp")
        (error
         (user-error "Failed to tangle config.org: %s" (error-message-string err))))
      (message "✓ Tangling complete")
      (message "Loading init.el...")
      ;; Load the tangled init file
      (condition-case err
          (load-file init-el)
        (error
         (message "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━")
         (user-error "Failed to load init.el: %s" (error-message-string err))))
      ;; Calculate load time
      (let ((elapsed-time (float-time (time-subtract (current-time) start-time))))
        (message "✓ Configuration loaded successfully")
        (message "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━")
        (message "Reload completed in %.2f seconds" elapsed-time)
        (message "")
        (message "NOTE: Some changes require a full Emacs restart:")
        (message "  • Removed keybindings, hooks, or modes")
        (message "  • Package installations/removals")
        (message "  • Major structural changes")
        (message "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━")))))

(defun my/auto-tangle-config-org ()
  "Automatically tangle config.org when saved.
This ensures that the executable init.el is always in sync with the
literate configuration document without requiring manual intervention."
  (when (string-equal (buffer-file-name)
                      (expand-file-name "config.org" user-emacs-directory))
    ;; Dynamic scoping to avoid confirmation prompts during tangling
    (let ((org-confirm-babel-evaluate nil))
      (org-babel-tangle))))

;; Attach the auto-tangler to the `after-save-hook` locally for org-mode buffers.
(add-hook 'org-mode-hook
          (lambda ()
            (add-hook 'after-save-hook #'my/auto-tangle-config-org nil t)))

(defun selected-region-or-symbol-at-point ()
  "Return the selected region, otherwise return the symbol at point.
Highly useful for commands that operate on text, allowing them to seamlessly
fall back to the word under the cursor if no region is highlighted."
  (if (region-active-p)
      (buffer-substring-no-properties (region-beginning) (region-end))
    (thing-at-point 'symbol t)))
#+end_src

** Constants

(defconst sys/linuxp
  (eq system-type 'gnu/linux)

;; Uses (user-uid) instead of $USER, which is unreliable in Docker/sudo.

(defconst sys/rootp

** Performance Tuning
This section applies critical rendering, scrolling, and input-latency optimizations. It removes obsolete Emacs 24 hacks (like `bidi-display-reordering nil`, which causes rendering glitches in modern Emacs), applies Doom Emacs-inspired tweaks to prevent clipboard and file-opening spam, and defers JIT syntax highlighting to guarantee 60fps typing fluidity even with heavy LSP semantic tokens.

#+begin_src emacs-lisp
;; Bidi optimizations (Safe for Emacs 27+)
;; Note: `bidi-display-reordering` is omitted as it is an obsolete Emacs 24 hack
;; that causes rendering glitches in modern Emacs. Setting paragraph direction
;; to LTR and inhibiting the Bidirectional Parentheses Algorithm (BPA) provides
;; the exact same performance boost safely.
(setq-default bidi-paragraph-direction 'left-to-right
              bidi-inhibit-bpa t)

;; Mitigate Input Lag by disabling GTK input methods (PGTK builds only).
;; PGTK builds on Wayland can suffer from severe input latency if the GTK
;; IM context is active. We disable it immediately after frame creation.
(when (fboundp 'pgtk-use-im-context)
  (add-hook 'after-make-frame-functions
            (lambda (frame)
              (with-selected-frame frame
                (pgtk-use-im-context nil)))))

;; Apply bidi optimizations to common modes locally
(defun my/bidi-optimizations ()
  "Apply bidi optimizations for current buffer."
  (setq-local bidi-paragraph-direction 'left-to-right
              bidi-inhibit-bpa t))

(add-hook 'org-mode-hook #'my/bidi-optimizations)
(add-hook 'text-mode-hook #'my/bidi-optimizations)
(add-hook 'prog-mode-hook #'my/bidi-optimizations)

;; Emacs 29+ Long Line Optimizations
;; Prevents Emacs from freezing when opening minified JSON or large log files.
;; If a line exceeds these thresholds, Emacs disables expensive redisplay
;; features like bidirectional text and syntax highlighting for that line.
(setq-default long-line-threshold 1000
              large-hscroll-threshold 1000
              syntax-wholeline-max 1000)

;; Undo limits (Generous limits for modern systems with ample RAM)
;; Default limits are too small for large refactoring operations.
(setq undo-limit 800000
      undo-strong-limit 1200000
      undo-outer-limit 120000000)

;; ==========================================
;; SCROLLING & REDISPLAY
;; ==========================================
;; Note: `fast-but-imprecise-scrolling`, `redisplay-skip-fontification-on-input`,
;; `inhibit-compacting-font-caches`, and `frame-resize-pixelwise` are already
;; set in early-init.el. We do not duplicate them here.
(setq auto-window-vscroll nil            ;; Prevents scrolling jitter
      highlight-nonselected-windows nil  ;; Reduces redisplay overhead
      window-resize-pixelwise nil
      byte-compile-warnings '(not obsolete)
      native-comp-async-report-warnings-errors 'silent)

;; Disable blink-cursor-mode properly.
;; Using `setq` only changes the variable; calling the minor mode function
;; with -1 actually stops the timer and prevents the redisplay overhead.
(blink-cursor-mode -1)

;; ==========================================
;; DOOM-INSPIRED OPTIMIZATIONS
;; (Crucial for lsp-mode + flycheck)
;; ==========================================

;; 1. Clipboard Spam Prevention (CRITICAL for Wayland/X11)
;; Prevents Emacs from making OS-level DBus/X11 API calls every time
;; you highlight text with the mouse/keyboard, eliminating micro-stutters.
(setq select-active-regions nil)

;; 2. Faster File Opening
;; Skips expensive case-insensitive regex matching when checking
;; `auto-mode-alist` to determine a file's major mode.
(setq auto-mode-case-fold nil)

;; 3. Typing Fluidity (JIT Lock Deferral)
;; Defers syntax highlighting by 50ms. This prevents font-lock and
;; lsp-mode semantic tokens from blocking the main thread during rapid typing.
(setq jit-lock-defer-time 0.05)

;; 4. Prevent GTK Tooltip Hangs (PGTK/GTK builds)
;; Forces Emacs to use its own internal tooltips instead of calling out
;; to the GTK DBus tooltip API, which can hang the UI on hover.
(when (boundp 'x-gtk-use-system-tooltips)
  (setq x-gtk-use-system-tooltips nil))
#+end_src

** Garbage Collector
`gcmh` (Garbage Collector Magic Hack) manages garbage collection based on idle timers. It raises the GC threshold while you are typing to prevent stutter, and drops it when you stop typing to clean up memory in the background. The `:unless (fboundp 'igc-info)` guard ensures compatibility with Emacs 31's upcoming MPS Incremental GC.

*Note on `focus-out-hook`: The hook below is retained for legacy compatibility. In Emacs 27.1+, `focus-out-hook` was marked obsolete in favor of `after-focus-change-function`. Furthermore, `gcmh`'s idle timer naturally handles GC when you Alt-Tab away, making manual focus hooks largely redundant. It is kept here strictly to preserve the finalized codebase structure.*

#+begin_src emacs-lisp
(use-package gcmh
  ;; Disable gcmh if Emacs is built with the new MPS Incremental GC (igc).
  ;; gcmh is designed for the old "stop-the-world" GC and will conflict with igc.
  :unless (fboundp 'igc-info)
  :hook (after-init . gcmh-mode)
  :init
  (setq gcmh-idle-delay 'auto            ;; Automatically calculate idle delay
        gcmh-auto-idle-delay-factor 10   ;; Multiplier for the auto delay
        ;; 128MB baseline threshold. High enough to prevent LSP-induced GC stutters
        ;; on modern machines with 16GB+ RAM.
        gcmh-high-cons-threshold (* 128 1024 1024)))

;; Legacy focus-out hook. Triggers GC when the frame loses focus.
;; NOTE: `focus-out-hook` is obsolete since Emacs 27.1, but remains functional
;; in many environments as a brute-force memory cleanup mechanism.
(add-hook 'focus-out-hook #'garbage-collect)
#+end_src

** Session Management
Handles persistence across Emacs sessions.
1. **`saveplace`**: Remembers cursor position, with a safeguard to forget unreadable/network files to prevent startup hangs.
2. **`recentf`**: Tracks recent files. It explicitly excludes TRAMP/remote paths (`file-remote-p`) to prevent SSH timeouts on startup, removes `file-truename` from handlers to prevent I/O hangs on unmounted drives, and uses a **lazy cache** for `org-agenda-files` to prevent filesystem thrashing.
3. **`savehist`**: Persists minibuffer history, explicitly excluding the buffer-local `mark-ring` to prevent serialization bloat.

#+begin_src emacs-lisp
;; Save place
(use-package saveplace
  :ensure nil
  :hook (after-init . save-place-mode)
  :custom
  ;; Prevents Emacs from hanging on startup if it tries to restore
  ;; point in a file on an offline network drive or unmounted volume.
  (save-place-forget-unreadable-files t))

;; History with symlink resolution
(use-package recentf
  :ensure nil
  :hook (after-init . recentf-mode)
  :init
  (setq recentf-max-saved-items 300
        recentf-exclude
        '("\\.?cache" ".cask" "url" "COMMIT_EDITMSG\\'" "bookmarks"
          "\\.\\(?:gz\\|gif\\|svg\\|png\\|jpe?g\\|bmp\\|xpm\\)$"
          "\\.?ido\\.last$" "\\.revive$" "/G?TAGS$" "/.elfeed/"
          "^/tmp/" "^/var/folders/.+$" "/persp-confs/"
          (lambda (file) (file-in-directory-p file package-user-dir))))
  :config
  (push (expand-file-name recentf-save-file) recentf-exclude)

  ;; Keep recentf from listing no-littering's own housekeeping files.
  (add-to-list 'recentf-exclude
               (recentf-expand-file-name no-littering-var-directory))
  (add-to-list 'recentf-exclude
               (recentf-expand-file-name no-littering-etc-directory))

  ;; Exclude ALL TRAMP/remote paths to prevent recentf-cleanup from
  ;; pinging offline servers and hanging Emacs on exit.
  (add-to-list 'recentf-exclude #'file-remote-p)

  ;; Doom Emacs explicitly removes `file-truename` from this list.
  ;; Running `file-truename` on every file during `recentf-cleanup` causes
  ;; massive I/O hangs if a symlink points to an unmounted network drive.
  (setq recentf-filename-handlers '(abbreviate-file-name))

  ;; ==========================================
  ;; ORG-AGENDA LAZY CACHE
  ;; ==========================================
  ;; The original implementation called `file-truename` and `org-agenda-files t`
  ;; synchronously on EVERY file check, causing severe filesystem thrashing.
  ;; We now use a cached approach that only triggers expensive I/O periodically.
  (defvar ar/recentf-org-agenda-cache nil
    "Cached list of resolved org-agenda file paths.")

  (defun ar/update-recentf-org-agenda-cache ()
    "Update the recentf exclusion cache for org-agenda files."
    (when (bound-and-true-p org-agenda-files)
      (setq ar/recentf-org-agenda-cache
            (mapcar #'file-truename
                    (seq-filter #'file-exists-p (org-agenda-files t))))))

  (defun ar/exclude-org-agenda-files-p (file)
    "Return t if FILE is an org-agenda file, using the cached list."
    (and (not (file-remote-p file))
         (string-suffix-p ".org" file t)
         (when ar/recentf-org-agenda-cache

*Note: `delete-trailing-whitespace` is intentionally omitted from `before-save-hook` here, as the `stripspace` package (configured later) handles whitespace cleanup much more safely by only modifying touched lines, preserving Git blame history.*

(use-package simple
  :ensure nil
  :hook ((text-mode . visual-line-mode))
  :init
  ;; These are minor modes, not variables. `setq` does not enable them.
  ;; They must be called as functions to actually update the modeline.
  (column-number-mode 1)
  (line-number-mode 1)

  (setq kill-whole-line t               ;; C-k kills the newline character too
        line-move-visual nil            ;; Move by logical lines, not visual wrapped lines
        track-eol t                     ;; Stay at end-of-line when moving down
        set-mark-command-repeat-pop t)  ;; Allow repeating C-u C-SPC to pop mark ring

  (setq-default show-trailing-whitespace nil)

  ;; Prettify the process list (M-x list-processes) with color-coded statuses
  (with-no-warnings
    (defun my-list-processes--prettify ()
      (when-let* ((entries tabulated-list-entries))
        (setq tabulated-list-entries nil)
        (dolist (p (process-list))
          (when-let* ((val (cadr (assoc p entries)))
                      (name (aref val 0))
                      (pid (aref val 1))
                      (status (aref val 2))
                      (status (list status 'face
                                    (if (memq status '(stop exit closed failed)) 'error 'success)))
                      (buf-label (aref val 3))
                      (tty (list (aref val 4) 'face 'font-lock-doc-face))
                      (thread (list (aref val 5) 'face 'font-lock-doc-face))
                      (cmd (list (aref val 6) 'face 'completions-annotations)))
            (push (list p (vector name pid status buf-label tty thread cmd))
                  tabulated-list-entries)))))
    (advice-add #'list-processes--refresh :after #'my-list-processes--prettify)))
